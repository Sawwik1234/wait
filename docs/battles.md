# Бои (Case Battles) — реализовано

## Механика

- **Создание**: 2 или 4 игрока, 1–10 раундов, 1–5 типов кейсов (раунд r использует
  кейс `(r−1) % len`). Создатель автоматически становится участником №1 и платит взнос.
- **Взнос** = сумма цен всех кейсов по раундам (`entryCost`), списывается при создании/join.
- **Приватные бои**: код приглашения 4–8 символов A-Z/0-9.
- **Автостарт**: когда занят последний слот — бой начинается сам.
- **Раунды**: каждый участник открывает раундовый кейс через тот же CSPRNG-пайплайн,
  что и обычное открытие (seed + roll в аудите). Предметы создаются сразу.
- **Победитель забирает всё**: предметные записи проигравших переприсваиваются
  победителю (транзакционно). Ничья — победа первого присоединившегося (детерминировано).
- **Отмена/выход** возможны только в WAITING, с полным возвратом взносов
  (`BATTLE_REFUND` в Ledger).

## Машина состояний

```
WAITING ──→ RUNNING ──→ FINISHED
   │
   └──→ CANCELLED (рефанды)
```

Переходы только через `BattlesService`; произвольные смены статуса невозможны.

## Realtime

Socket.IO, namespace `/realtime`, комнаты `battle:{id}`. События:
`battle:joined`, `battle:starting`, `battle:finished`, `battle:cancelled`.
Подписка: `socket.emit('subscribe', { battleId })` или query при handshake.

**Фолбэк**: если WebSocket недоступен (прокси/браузер), фронт автоматически
переходит на REST-поллинг раз в 1.5–2.5 с — бой работает в любом случае.

## Честность экономики

Бои не создают AP из воздуха: взносы сжигаются через `BATTLE_JOIN`,
возвраты приходят только из `BATTLE_REFUND`, предметы перераспределяются,
а не дублируются. Боты участвуют без денег (демо-актёры), их предметы
в банке — настоящие предметы из пула кейсов.

## Боты

`POST /api/battles/:id/fill-bots` — только создатель, только в WAITING:
дозаполняет слоты ботами и запускает бой.

## Античит

- Присоединиться после старта нельзя (`CONFLICT`).
- Провести бой дважды нельзя (статусная машина + `runBattle` проверяет WAITING).
- Дубликаты наград невозможны: `BattleRoundResult.inventoryItemId @unique`.
- Отправить «я победил» с клиента нельзя — победителя считает сервер.
